# EgoCraft web app (moved)

EgoCraft's web app is now built and published from the main repository,
[nu-stats/egocraft](https://github.com/nu-stats/egocraft), at
**https://nu-stats.github.io/egocraft/**.

This repository is archived. Its address,
https://nu-stats.github.io/egocraft-app/, now only sends visitors to the new
one, and its service worker clears the old offline copy. Studies and
interviews kept in the browser are kept for the whole site, so they carry
over to the new address.

On an iPad: remove the old Home Screen icon, open the new address in Safari,
and choose Share ▸ Add to Home Screen.
