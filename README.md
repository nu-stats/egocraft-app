# EgoCraft (web app)

**Open it: https://nu-stats.github.io/egocraft-app/**

EgoCraft is an app for egocentric network analysis: design a
questionnaire, run interviews by touch with the answers kept encrypted on the
device, import survey files, check them, draw each person's network, compute
the measures you choose, fit models, and export one row per person with the
Stata and R code that reproduces every number.

This repository holds only the built app, so it can be opened at a web
address. That is what iPads need.

## On an iPad

1. Open https://nu-stats.github.io/egocraft-app/ in Safari.
2. Tap the Share button, then **Add to Home Screen**.
3. Open EgoCraft from the Home Screen. From then on it opens full screen,
   with or without a network.

The first visit stores the whole app on the device. When a new version is
published, the app says so the next time it is opened with a network.

## Your data stays on your device

Everything runs in the browser. Files you open are read on the device,
studies and interviews are kept in the browser's own storage (interviews
encrypted with your passphrase) and in the files you save, and nothing is
sent anywhere: this site only hands out the app's files. Save your study as
a file now and then, because Safari can clear what it keeps after some weeks
without a visit.
